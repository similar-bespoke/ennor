Mastervolt USB Interface
Product code: 77030100

The Mastervolt USB Interface makes it possible to read in and configure your Mastervolt products in a
MasterBus configuration or a CZone network from your Windows device.


For MasterBus the required MasterAdjust software can be downloaded below.
MasterAdjust allows you to monitor and configure live system data, giving you full control over your
Mastervolt products.


For CZone systems the necessary Configuration tool can be downloaded from CZone portalCZone portal.


A MasterBus CZone drop cable is also required and can be found on the accessories pageaccessories page
